# AEGIS Swarm v0.4.2 — First Public Beta

**Release date:** 2026-07-31  
**Status:** Authorized defensive **beta** (first published release)

## Highlights

- 63-agent control plane (SOC / DFIR / purple / intel / reporting)
- Engagement lifecycle with approve / abort gates
- SQLite offline mode + Postgres-ready storage
- Redis Streams bus with Sentinel-aware client + monitoring metrics
- Evidence hash chain, ATT&CK coverage, signed audit export, HTML reports
- Production fail-closed auth (`AEGIS_ENV=production`)
- LICENSE + SECURITY.md
- Hardening: TrustedHost, CORS, body size, optional rate limit
- **3D Operator Console** (`console/`) — single-file executable build

## Quick start

```bash
pip install -e ".[dev]"
./scripts/run_local.sh
# API http://127.0.0.1:8080

python3 console/launcher.py
# 3D UI http://127.0.0.1:8765
```

### Console single executable

```bash
cd console && ./build_console.sh
./dist/AEGIS-Console
```

## Production

```bash
export AEGIS_ENV=production
export AEGIS_API_KEY='…'   # required unless OIDC configured
export AEGIS_AUDIT_SIGNING_KEY='…'
```
