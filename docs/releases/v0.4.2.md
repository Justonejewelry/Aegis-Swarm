# AEGIS Swarm v0.4.2

**Release date:** 2026-07-31

## Highlights

- Control plane parity on GitHub: auth, metrics, evidence, ATT&CK, signed audit, reports
- X-Request-ID middleware
- DFIR timeline: `GET /engagements/{id}/timeline`
- EvidenceRepository (Postgres evidence chain)
- Expanded CI: Python 3.11/3.12, ruff fail-on-error, import smoke, docker build

## Tagging (manual)

```bash
git tag -a v0.4.2 -m "AEGIS Swarm v0.4.2"
git push origin v0.4.2
```

Then create a GitHub Release from tag `v0.4.2` using this document as the body.
