# AEGIS Swarm v0.2.0

**Release date:** 2026-07-30  
**Codename:** Catalog & Bus

## Highlights

- **Full catalog coverage** — 63 specialized agents implemented and registered across Command, Blue, Intel, Purple, Red (authorized), DFIR, and Reporting domains
- **Redis Streams task bus** with automatic in-memory fallback for local/dev
- **Background worker** loop that consumes tasks, enforces engagement scope, and dispatches to agents
- **Ingestion connector stubs** for Syslog, Elasticsearch, and Microsoft Sentinel plus a common normalize pipeline
- Compact agent helpers (`AnalyticAgent`, `ResultAgent`) to accelerate catalog expansion
- Updated unit tests covering registry count, bus, worker, and ingestion

## Implemented agents (63)

See [Agent Catalog](../agents/CATALOG.md). All domains from the original 64-agent target are represented; one planned agent (`global-orchestrator`) remains as future work (logic currently lives in the orchestrator + mission-controller).

## Task bus usage

```bash
# API
uvicorn aegis.api.main:app --port 8080

# Worker (uses Redis when AEGIS_REDIS_URL is set)
python -m aegis.messaging.worker
```

Enqueue tasks via `POST /tasks`.

## Security posture (unchanged)

- Only `ACTIVE` engagements accept work
- Red/Purple agents produce plans, coverage matrices, and validated findings only — no live exploitation
- Audit hooks on agent decisions
