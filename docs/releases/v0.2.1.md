# AEGIS Swarm v0.2.1

**Release date:** 2026-07-30  
**Codename:** Persistence & Graph

## Highlights

- **Durable state**: async PostgreSQL repositories for engagements, findings, and audit
- **Knowledge graph**: shared NetworkX GraphStore used by attack-path-modeler and privilege-graph-analysis; optional `graph_edges` table
- **Operator UX**: HTML executive report (`/engagements/{id}/report`), Streamlit dashboard, Grafana provisioning
- **Ingestion**: CrowdStrike + Defender connectors with Settings-driven credentials
- **Worker**: finding persistence, DLQ, multi-worker ready
- Docker Compose now runs API + worker + Grafana

## Upgrade notes

- New env vars: `AEGIS_PERSIST_FINDINGS`, connector credentials (see `aegis.core.settings`)
- Schema adds `graph_edges` — re-run `schemas/sql/init.sql` or let GraphStore create it
- API version string is `0.2.1`

## Security posture (unchanged)

Scoped engagements, authorized validation only, no live exploitation.
