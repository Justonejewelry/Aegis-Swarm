# AEGIS Swarm v0.1.0

**Release date:** 2026-07-30  
**Codename:** Foundation

## Highlights

- Production-oriented **multi-agent control plane** for authorized cyber defense
- **20 implemented agents** (catalog documents 64 planned)
- Engagement lifecycle with approval gates and kill-switch path
- Risk scoring + ATT&CK-oriented purple/red validation agents
- Docker / K8s starters and CI

## Implemented agents

| Domain | Agents |
|--------|--------|
| Command | mission-controller, health-monitor |
| Blue | siem-correlator, threat-hunter, authentication-analyst, network-traffic-analyst |
| Intel | attack-mapper, ioc-correlator, cve-intelligence |
| Purple | detection-validator, rule-coverage-analyst, security-gap-analyst |
| Red | attack-path-modeler, privilege-graph-analysis, adversary-emulation-planner |
| DFIR | timeline-builder, root-cause-analyst |
| Reporting | executive-reporter, recommendation-engine, risk-prioritization |

## Install

```bash
git clone https://github.com/Justonejewelry/Aegis-Swarm.git
cd Aegis-Swarm
pip install -e ".[dev]"
pytest -q
uvicorn aegis.api.main:app --port 8080
```
